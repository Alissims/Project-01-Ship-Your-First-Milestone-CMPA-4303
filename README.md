Aunt Mae's Treats
What is this?

A little landing page for Aunt Mae's Treats  a jam and banana bread business. It shows what's available (jam in 4 oz, 6 oz, and 8 oz jars, plus whole loaves of banana bread), with a size picker that updates the price and jar size as you click through. No online checkout — every order is a DM on Instagram.

Why does it exist?

Aunt Mae's Treats started in a home kitchen  jars for friends and family that turned into something worth selling. This site gives it a real front door: somewhere to point people who keep asking "what's available and how much?" instead of explaining it in DMs for the tenth time. No storefront yet, so keeping ordering personal (a real conversation, not a cart) just makes sense for how the business runs right now.

Tools I used

HTML, CSS, JavaScript  no framework. One purpose-built page; plain fundamentals were all it needed.
